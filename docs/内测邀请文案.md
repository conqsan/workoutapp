## 完整版（推荐）

```
做了个健身记录 App，开源放在 GitHub 上了，想请你帮忙试用一段时间，有问题随时骂我。

在线使用：https://conqsan.github.io/workoutapp/
开源地址：https://github.com/conqsan/workoutapp
不用注册、不用登录，打开就能用。

【装到手机上（推荐）】
· 安卓：用 Chrome 打开 → 右上角菜单 → 「安装应用」/「添加到主屏幕」
· iPhone：用 Safari 打开 → 底部「分享」→「添加到主屏幕」
（如果在微信里点开，先右上角「···」→「在浏览器打开」，再按上面操作）
装好后从桌面图标启动就是全屏，打开过一次之后断网也能记录。

【怎么用】
1. 训练：底部「训练」→ 选日期 → 开始训练 → 加动作（先选部位再选动作，没有的可以自己建）
   → 填重量、次数、休息 → 完成训练。重量支持 kg / lb，可以一键「复制上一组」。
2. 补记：训练页的「训练日期」可以改成前几天，用来补录忘记的训练。
3. 补剂：「补剂」页选补剂（增肌粉 / 肌酸 / 蛋白粉，蛋白粉和增肌粉可以按「勺」记）
   → 填用量 → 选时间 → 添加。
4. 回看：「历史」看每次训练的明细（日期、备注、每一组的重量次数都能改，也能删）；
   「统计」看本周 / 本月训练量、各部位次数、单项最大重量趋势。

【两件重要的事】
· 数据只保存在你手机的浏览器里，没有云同步 —— 换浏览器或清理浏览器数据会丢。
· 所以建议隔段时间备份一次：「我的」→「导出 JSON」，把文件存网盘或发给自己；
  换手机时用「导入 JSON」选这个文件即可（是合并，不会覆盖你新手机上已有的记录）。

【想请你反馈的】
· 哪一步觉得麻烦、看不懂、找不到按钮；
· 你常练的动作 / 常吃的补剂有没有缺；
· 有没有数字对不上或者记录丢失的情况（遇到的话告诉我当时在做什么）。

代码全部开源，随便看、随便提建议；有问题也可以在 GitHub 上开 issue。
用着还顺手的话，麻烦给仓库点个 ⭐ star 支持一下，谢谢！
```
