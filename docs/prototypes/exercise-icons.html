缩放检查

动作选择器里会用小尺寸，所以先看一眼 40px 还能不能认出来。

这一版改了什么

  • 侧视只画靠镜头的一臂一腿（卧推 / 深蹲 / 划船 / 卷腹 / 臀推 / 下压），不再两只手叠在一起
  • 躯干加粗、手脚收细，头和人形之间留出空隙，不再糊成一团
  • 器材一律避开身体轮廓：杠铃画在身体外侧，配重块不压在手臂上
  • 青色箭头改到轮廓外侧，不碰肢体
  • 正面动作（引体 / 侧平举 / Y字）保留双手 —— 那边是对称的，两条手臂不会互相遮挡

还要你确认：姿势准不准。你说哪个别扭（比如「深蹲看着像硬拉」「卷腹的手看不清」）， 我改坐标就行 —— 一个动作就是十几个数字，不用重画。
